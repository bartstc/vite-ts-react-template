# Docs Writing

- Write and edit docs, skills and rules in Simplified Technical English. Read `docs/writing-style.md` before you write.
- When you change existing text, keep the technical meaning exactly. Keep "must", "should" and "may" exact.
- Do not change code blocks, commands or output samples.
